# Changelog

Todos los cambios notables en este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v0.2.0] - 2025-11-19

### Fixed
- Eliminado Vercel Analytics para compatibilidad con Easypanel
- Configuración de variables de entorno locales (.env.local)
- Resuelto error "Service is unavailable" en preview de Trae IDE
- Corregido error de variables de Supabase en servidor

### Changed
- Mejorado el sistema de control de versiones
- Implementado semantic versioning
- Actualizada versión mostrada en UI de "v154" a "v0.2.0"

## [v0.1.0] - 2025-11-18

### Added
- Proyecto inicial de RentaFlow Dashboard
- Integración con Supabase
- Sistema de autenticación
- Diseño básico con Tailwind CSS

### Fixed
- Configuración de Dockerfile para producción
- Variables de entorno de Supabase con prefijo NEXT_PUBLIC_
- Path aliases en TypeScript
